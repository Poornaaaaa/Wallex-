# Wallex 
Project Description: Describes Wallex as a premium, glassmorphism-based client-side expense tracker and financial advisor built with React and integrated with Supabase.
Features & Capabilities:
Interactive Visual Analytics: Details the SVG Expense Pie Chart segment interactions, tooltips, and dynamic legend.
Transaction Ledger: Explains the transaction form, CRUD actions, Indian Rupee (₹) formatting, and category tags.
Category Budgets: Covers budget limits per category and real-time threshold warnings.
Lockable Administration Vault: Explains security passcode protection, audit logging, user lists, and JSON data backup exports.
Supabase Cloud Sync: Outlines how users can configure their database sync configuration keys.
Dynamic Styling: Details the dual light/dark modes and full responsive layout engine.
Technology Stack: Documents the use of React 18, Babel Standalone (zero-build architecture), Supabase JS Client, and custom CSS variables/animations (like floating background blur orbs).
Local Startup Guide: Provides copy-pasteable commands for starting the application locally using Python (http.server) or Node.js (npx serve).
